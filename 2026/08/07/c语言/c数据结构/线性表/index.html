线性表

线性表是由 n (n ≥ 0) 个相同类型的数据元素构成的有限序列，其中每个元素（除第一个和最后一个）都有唯一的前驱和后继。数据元素之间的关系是一对一的关系。在计算机中，线性表主要有两种实现方式。

顺序存储 —— 顺序表

顺序表用一段地址连续的存储单元依次存储线性表的数据元素。逻辑上相邻的元素物理位置也相邻，便于随机存取，但插入删除需要移动大量元素，效率低。

链式存储 —— 线性链表

线性链表用一组地址任意的存储单元存储线性表的数据元素。逻辑上相邻的元素通过指针链接，物理位置不一定相邻，便于进行插入和删除操作，只需修改指针无需移动大量元素，但无法随机存取，只能从表头开始顺序查找，效率低。

线性链表的实现

线性表基本运算的链表实现，有单链表和双链表两种常见的方式。

单链表

单链表由一个个结点组成，每个结点包含数据域和指针域，指针域指向下一个结点。

单链表的初始化

单链表的创建方法一般有两种。

头插法

头插法建表从空链表开始，反复执行以下操作直到建表程序结束：

  • 读入用户输入的数据buffer；
  • 若buffer有效, 则创建新结点q (q->data=strdup(buffer));
    若buffer无效——读入的数据buffer为结束标志(例如END), 则建表程序结束;
  • 然后, 将结点q插入在链表头部, 作为链表的首结点;

利用头插法创建单链表会导致结点的次序和输入的顺序相反。

尾插法

尾插法建表从空表开始,先保存链表尾结点指针p(初始时刻 p=head), 然后反复执行以下操作直到建表程序结束：
首先, 读入数据buffer。
若buffer有效, 则创建新结点q (q->data=strdup(buffer));
若buffer无效——读入的数据buffer为结束标志(例如END), 则建表程序结束;
然后, 将新结点q插入到当前链表的末尾，使其成为当前链表的尾结点, 并更新p (p = q);

和头插法不同，利用尾插法创建的单链表不会导致顺序反转。

头插法和尾插法产生差异的原因
  • 头插法：每次将新结点插入到头结点之后（即链表的最前端），后输入的数据不断“压”到前面，所以先输入的数据被挤到后面，最终顺序与输入顺序相反。
  • 尾插法：每次将新结点插入到链表尾部（借助尾指针快速定位），数据按输入顺序依次往后接，最终顺序与输入顺序相同。

单链表核心功能

插入

单链表的插入操作是在单链表的第i个结点处插入新结点q。需要先找到第i-1个结点，然后执行插入操作。

删除

单链表的删除操作是在链表中移除第i个结点，需要先找到第i个结点,释放其内存，再将第i-1个结点指向第i+1个结点。

更改

更改第i个结点的值，需先遍历找到该结点，然后释放其原有的数据域内存，再重新存入新值即可。

输出

输出第i个结点的值，需先遍历找到该结点，判断其是否存在，若存在则输出其数据域的值；若位置无效则给出错误提示。

如果想要按顺序输出单链表内所有结点的值，只需要遍历一遍链表即可。
