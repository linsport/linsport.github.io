线性表

线性表是由 n (n ≥ 0) 个相同类型的数据元素构成的有限序列，其中每个元素（除第一个和最后一个）都有唯一的前驱和后继。数据元素之间的关系是一对一的关系。在计算机中，线性表主要有两种实现方式。

顺序存储 —— 顺序表

顺序表用一段地址连续的存储单元依次存储线性表的数据元素。逻辑上相邻的元素物理位置也相邻，便于随机存取，但插入删除需要移动大量元素，效率低。

顺序表核心功能

插入

为了在第i个元素处实现插入操作，直接通过下标定位到第 i 个位置。然后将该位置及之后的元素整体后移，腾出空位，最后放入新元素。

  • 当元素个数已达容量上限（len == capacity）时，先用 realloc 扩充为原来 2 倍 的空间。使用临时指针 newData 接收返回值，避免扩容失败时丢失原数据。成功后同步更新 data 和 capacity。

删除

删除第i个结点

为了在第i个元素处实现删除操作，直接通过下标定位到第 i 个位置。然后将该位置及之后的所有元素向前移动一格，覆盖被删位置，保持顺序表的连续性。

  • 返回字符串指针，将内存所有权交给调用者，调用者需在适当时候 free(removed) 以避免内存泄漏。
